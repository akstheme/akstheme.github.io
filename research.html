Active · 2022–Present Cybersecurity

Network Telescope Feed for Threat Intelligence Generation

This project focuses on building a highly scalable cyber security infrastructure that collects, processes, and analyzes Internet Background Radiation (IBR) using a Network Telescope (Darknet). By monitoring a large block of unassigned, routed IP addresses that should receive zero legitimate traffic, the system treats 100% of incoming data as anomalous or malicious. The project ingests this passive network traffic in real time and uses automated data engineering pipelines and machine learning to generate high-fidelity Cyber Threat Intelligence (CTI).
